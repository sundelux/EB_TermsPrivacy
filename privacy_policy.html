Privacy Policy

Data Processing Notice for Private Banking Integration
Data Controller: Private Individual (Self)
Regulation: GDPR Art. 2(2)(c) Compliant
Target Data: Own Bank Accounts Only
Third-Party Sharing: None (0%)

1. Overview

This Privacy Notice describes how financial data is handled within this personal integration project ("Application"). The Application is developed and operated by a private individual strictly for personal, non-commercial use (Data Subject and Data Controller are the same individual). The Application accesses financial data solely from bank accounts owned by the Operator.

2. Categories of Data Processed

Through the Enable Banking API, the Application retrieves account information and transaction histories from the Operator's explicit bank accounts, including:

  • Account details (e.g., IBAN, account balance, currency)
  • Transaction history (e.g., date, amount, payee/payer details, remittance information)

3. Purpose and Legal Basis of Processing

Data processing is conducted exclusively for personal budgeting, expense tracking, and private financial analysis. The legal basis corresponds to explicit consent (GDPR Art. 6(1)(a)) and the household exemption for purely personal activities under GDPR Art. 2(2)(c).

4. Data Storage & Third-Party Policy

  • Zero Third-Party Sharing: Retrieved banking data is never shared, sold, rented, or transferred to any third party, marketing service, or commercial platform.
  • Private Local Storage: All processed data remains strictly within the Operator's private local environment or encrypted private storage systems.
  • No Public Exposure: No personal financial data is stored in or rendered visible through public repositories or public web interfaces.

5. Consent & Data Control

API access tokens and authorization credentials are maintained in secure configuration files excluded from public view. Consents granted via Enable Banking can be revoked at any time by the Operator directly through their bank or the Enable Banking interface.

6. Administrative Contact

For data protection inquiries regarding this repository, please reach out via the communication tools provided by the repository host platform (e.g., Repository Issues).
